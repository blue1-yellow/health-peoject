# 上线前检查清单

## 已完成

- 登录、注册、用户信息和饮食/运动/情绪记录接口使用 JWT 用户隔离。
- 饮食记录支持新增、查询、编辑和删除。
- AI Agent 工具仅允许查询当前用户近 7 天的饮食、运动和情绪汇总。
- AI 高风险内容有安全兜底，图片识别接口限制图片大小并要求登录。
- AI 响应包含可信资料来源，图片识别返回确认后保存的 JSON 结果。

## 真实模型联调前

1. 配置 ARK_API_KEY、ARK_MODEL 和 ARK_BASE_URL，不要提交到 Git。
2. 使用 Apifox 验证登录、AI 问答、日报和 /ai/food-image。
3. 检查无 token、错误 token、空 Body、超长问题、超大图片和错误图片类型。
4. 验证两个不同账号不能读取或修改对方的健康记录。
5. 前端执行 npm run build，后端执行 .\mvnw.cmd test。

## 上线部署前

- 将数据库账号密码改为环境变量。
- 在服务商控制台设置调用额度和告警。
- 将每日 AI 次数从内存计数迁移到数据库或 Redis。
- 使用 HTTPS，并限制 CORS 到正式前端域名。
- 配置日志脱敏，不能记录 API Key、JWT 或图片原文。
- 使用生产数据库备份和恢复方案。
